## 常见问题

**设了中文，界面还是英文？** 说明你改的是回复语言，不是界面语言。界面语言归客户端管，要走汉化补丁那条路。

**官方升级之后汉化就没了？** 不是被官方修掉了，是版本变了，补丁和客户端的对应关系跟不上了。等适配，别去装旧版客户端。

**要不要为了汉化装旧版本？** 不要。旧版本拿不到新的模型和修复，捡了芝麻丢西瓜。

**汉化会影响官方更新和签名校验吗？** 不替换、不重新打包官方文件就不会。改的是客户端本来就内置的语言资源开关。
