# 老手启动器3.0.48更新：完善Claude配置窗口汉化，修正状态

> 原文链接：[https://www.laoshoucun.com/jiaocheng/3779](https://www.laoshoucun.com/jiaocheng/3779)

Claude 主界面已经显示中文，点开「推理配置」却还是英文；或者窗口明明已经汉化，老手启动器仍显示「中文待定」。前一种是独立窗口没有跟上，后一种是状态判断没有跟上，这一轮更新分别处理这两个问题。

在完善配置窗口中文处理的同时，也精简了重复的启动按钮。对于已经完成持久中文验证的普通版客户端，启动器现在能够重新核验并显示对应状态，让看到的提示更符合实际情况。

这一版更新了什么

配置窗口汉化：显式汉化成功后，观察本次 Claude 进程后来打开的推理配置窗口，在用户切到该窗口时加载中文；保留帮助中的手动入口。

自动任务修复：修复 Windows 路径写法不同导致观察任务提前退出的问题，补充失败日志；3.0.46 已完成本机安装版手动及新开窗口自动汉化验证。

翻译补充：完善配置窗口中「插件」等文字，并分别核对标题、搜索和应用按钮的中文显示。

操作精简：删除重复的「启动原版 Claude」按钮及关联提示，保留「重启中文 Claude」、实际错误提示和算力中心入口。

状态修复：对已完成持久中文验证的普通版客户端，运行时正确显示绿色「中文启用」，未运行时显示「中文就绪」。

判断完善：状态核验结合主界面与配置窗口验证记录、客户端版本、实际资源和运行路径；重新打开启动器或扫描后可再次确认，避免重启结束又退回「中文待定」。

状态栏这一格：已验证持久中文的客户端运行时显示「中文启用」，未运行显示「中文就绪」

使用时可以留意什么

3.0.48 主要完善已验证持久中文客户端的状态识别。持久中文需要先完成对应准备和验证，单独升级启动器不会自动完成全部汉化步骤。如果客户端升级或资源改变，旧验证记录会失效，需要重新确认，不能仅凭启动参数判断已经汉化。
