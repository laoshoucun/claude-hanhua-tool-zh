# 老手启动器3.0.38更新：数据独立，Claude汉化线路切换更完整

> 原文链接：[https://www.laoshoucun.com/jiaocheng/3777](https://www.laoshoucun.com/jiaocheng/3777)

有些用户会同时安装老手启动器和其他线路管理工具。各自保存的线路、设置和当前状态，应该有清楚的归属；而从算力中心点击导入时，也需要能在老手启动器里接收并确认，再把线路交给中文 Claude 使用。

这一轮更新重点完善独立数据目录、所选线路应用和 CCS 浏览器导入兼容。日常使用时，可以更清楚地管理老手自己的配置，同时保留从现有算力中心按钮导入线路的便利。

这一版更新了什么

数据隔离：数据库、设置、运行状态、备份、日志和客户端配置迁入老手专属目录，使用独立端口与 Claude 配置。

线路切换优化：从支持的应用分类选择普通 API 线路后，点击「重启中文 Claude」，可按所选配置生成对应的桌面线路和模型名单。

模型修复：使用所选线路自己的认证信息获取模型，避免跨分类启动时继续沿用不适用的默认模型。

入口恢复：新配置默认显示顶部路由和项目切换入口，同时保留用户明确设置的隐藏偏好；补齐提示词、会话管理的中文名称。

启用修复：启用需要模型映射的 Desktop 线路时自动进入所需路由模式，减少额外手动操作。

浏览器兼容：运行期间兼容算力中心现有的 ccswitch:// 导入按钮；正常退出后恢复原关联，并处理异常退出后的恢复与转交。

线路卡片上的「刷新」和「更新模型」：3.0.38 起用所选线路自己的认证信息取名单，不再串用默认模型

使用时可以留意什么

浏览器协议兼容仅用于接收导入链接，两产品的线路、数据库与客户端配置继续独立。从浏览器导入后，先在确认框核对内容，再保存或启用。顶部路由入口显示出来，不代表已经自动开启路由；实际模式以界面状态为准。
