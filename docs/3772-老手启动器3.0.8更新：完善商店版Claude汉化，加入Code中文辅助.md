# 老手启动器3.0.8更新：完善商店版Claude汉化，加入Code中文辅助

> 原文链接：[https://www.laoshoucun.com/jiaocheng/3772](https://www.laoshoucun.com/jiaocheng/3772)

同样是 Claude，官网下载的安装版和 Microsoft Store 商店版，在启动方式、资源位置和配置目录上会有区别。对使用者来说，装好以后能从老手启动器正常打开、读取自己的配置，才是最直接的需求。

围绕这个问题，这一轮更新重点完善商店版 Claude 的支持，减少首次汉化时不必要的文件复制，并加入 Claude Code 中文辅助入口。老手启动器继续把中文启动和线路管理放在一起，让常用操作更集中。

这一版更新了什么

启动修复：调整商店版 Claude 的启动方式，支持通过系统执行别名或应用入口唤起客户端。

配置修复：完善商店版第三方线路的配置路径识别，减少配置已保存、客户端却没有读取到的问题。

汉化优化：商店版改为使用原安装和原用户资料，不再为汉化复制整套客户端，减少首次处理的磁盘占用。

识别修复：区分启动别名和真实资源目录，修复部分商店版客户端找不到语言资源的问题；重复点击重启时避免并发操作。

新增功能：加入 Claude Code 中文辅助层，提供启用与修复入口；完整 CLI 汉化仍取决于安装方式及版本支持情况。

帮助优化：使用帮助支持读取远程客服信息；接口不可用时使用内置联系方式。

线路列表里 Claude Desktop Official 与第三方线路并列，商店版和官网安装版都从这里选好再启动

使用时可以留意什么

从商店安装 Claude 的用户，可以重点关注这一阶段的兼容改动。Claude Code 中文辅助与 Desktop 界面汉化分别处理，具体支持范围仍以安装方式和客户端版本为准。
