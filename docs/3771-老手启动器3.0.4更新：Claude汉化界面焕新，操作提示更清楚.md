# 老手启动器3.0.4更新：Claude汉化界面焕新，操作提示更清楚

> 原文链接：[https://www.laoshoucun.com/jiaocheng/3771](https://www.laoshoucun.com/jiaocheng/3771)

老手启动器把 Claude 中文界面启动、线路管理等常用操作放在一个窗口里。平时打开软件，可以查看当前状态、管理线路，也可以通过「重启中文 Claude」进入客户端。第一次接触的朋友，可以先从界面上的这几个入口了解它。

这一轮更新，先把每天都会看到、点到的地方整理了一遍：统一界面风格，突出主要按钮，同时让窗口布局和环境提示更清楚。下面是 3.0.4 及此前几个小版本的主要变化。

这一版更新了什么

界面优化：主窗口、顶部栏、线路卡片和底部操作区采用玻璃质感，保留青绿色主色，并适配深色模式。

操作优化：突出「重启中文 Claude」主按钮，右上角扫描入口调整为「手动汉化扫描」。

窗口优化：调整默认窗口尺寸及最小尺寸，兼顾内容展示和小窗口使用；保留用户自行调整的窗口大小。

图标优化：统一应用与安装包的品牌图标，并分别调整桌面快捷方式、任务栏和托盘的显示效果。

提示修复：环境变量冲突提示按当前应用分别显示，避免在 Claude 页面出现 Codex、Gemini 等应用的无关告警。

老手启动器主窗口：顶部是应用与项目切换，中间是线路卡片，底部主按钮就是「重启中文 Claude」

使用时可以留意什么

初次使用时，可以先确认当前应用和线路，再点击需要的操作。环境提示会跟随当前应用显示，处理起来也更容易对应。

汉化工具下载与版本信息：老手村 Claude 汉化下载页。
