# Claude 悄悄上线中文界面，大陆用户还是进不去

> 原文链接：[https://www.laoshoucun.com/claudedt/3525](https://www.laoshoucun.com/claudedt/3525)

Claude 换了一张脸。

网页端和桌面端一打开，先弹出一个语言选择框。

中文（简体）稳稳打着勾。

旁边还并排站着繁体。

不只是语言项变了。

按钮，菜单，设置页，整页都成了中文。

语言列表一口气拉到三十多种。

网页和桌面端先上，手机 App 还没跟上。

对不少想用上这类 AI工具 的大陆用户，这却像一场空欢喜。

更刺激的一幕在结账页。

账户国家的下拉菜单里，赫然躺着中国大陆。

每月二十美元的档，两百美元的顶配档，都能选。

看到这一步，社交平台上的中文博主先泼了一盆冷水。

小心，这可能是钓鱼执法的新招。

大家这么警惕，是被钓怕了。

上个月底，它放过一批两百五十美元的额度福利。

有人上午刚领完，中午就收到一封邮件。

发信的是它自己的安全团队。

理由只有一行，违反支持地区政策。

账号当场被封。

有人把这事总结得很扎心。

早起的鸟儿有虫吃。

早领的号有封号吃。

这个月初，它又开始送实体小玩偶。

收货表单里，国家一选中国大陆，下面就多出一栏。

要填十八位身份证号。

别人领的是周边，你领的是一次实名核验。

一只橙色的小玩偶，换一个十八位的号码。

这笔账，网友自己会算。

宁可不用，也别交号。

从两百五十美元额度，到小玩偶，再到今天的中文界面。

网友顺手把它排成了连续剧的第三季。

门其实还锁着

闹得再热，门也没有打开。

最先爆料的博主很快出来澄清。

账户结算页能选中国大陆是真的，事情也就到此为止。

它对外公布的支持地区名单里，C 开头的国家从智利直接跳到哥伦比亚。

中国大陆和中国香港、中国澳门，一个都不在名单上。

在最火的几款 AI对话 产品里，它是唯一还挂着地区限制的一个。

一个下拉菜单，改不了一份名单。

与其对着菜单猜，不如去看名单。

真要开这个口子，动的是它的条款和公告。

这一年，它对中国市场的态度一直写在明面上。

去年九月起，中资控股过半的公司一概不卖。

今年七月，又明令禁止在不支持的地区访问。

验证身份要证件原件加实时自拍，翻拍扫描一律不认。

它的掌门人也一直力挺对华的出口管制。

这屏中文，是给谁看的

答案不在大陆。

新加坡和马来西亚的华人，在英美澳读书的中国留学生，本来就是它的用户。

以前他们面对的是一整屏英文菜单。

现在终于能看中文了。

说起来，它的帮助页面早就有简体中文。

语音也早就能说普通话。

偏偏界面一直拖到今天才补上。

它最早靠 AI编程 起家，用户大多在写代码。

这么急着补，是因为它想冲出程序员的小圈子。

一份最新的消费 AI 榜单上，它的收入排到了第二。

在付费订阅人数上，它和对手的差距从八倍缩到了三倍。

可它近半年的新功能里，真正面向普通用户的只有百分之二点六。

程序员神器想变成大众产品，第一步就是让人看懂菜单。

至于大陆这边。

它中文说得再顺，也只回一句。

此地区暂不支持。
