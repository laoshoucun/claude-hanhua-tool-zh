# Claude汉化工具下载和克劳德保姆级汉化教程

> 原文链接：[https://www.laoshoucun.com/jiaocheng/3770](https://www.laoshoucun.com/jiaocheng/3770)

大家都知道，Claude 默认是中文的，可界面全是英文，用起来非常不方便。那它怎么汉化呢？？

汉化其实很简单。就三步。

第一步，打开网站，下载对应的汉化工具包。地址是 https://www.laoshoucun.com/hanhua。打开之后找到「汉化安装包」那一块。下面有 Windows 版下载和 MacOS 版下载两个按钮。按自己的电脑系统选一个就行。

第二步，把下载好的工具装好。双击安装包。一路点下去就行。没有什么要特别设置的选项。装完桌面上会出现这个工具的图标。

第三步，点击「重启中文Claude」。打开这个工具。找到界面上的「重启中文Claude」按钮。点它。Claude 会自己关掉再重新打开。再打开之后，界面就是中文版了。

这个汉化会随着 Claude 版本升级自动更新。以后 Claude 官方升级新版本，你不用重新下载汉化包。它会自己适配。一直保持中文。

咱们这个汉化工具，除了汉化之外，还可以选择不同的 Claude 线路。官方线路连不上的时候，换一条就能接着用。还能添加 DeepSeek 等自定义模型。想加什么模型，自己加进去。

最后，咱们这个工具，它还是软件入口。以后要用 Claude，从这个工具进去就行。汉化在这。换线路在这。加模型也在这。不用来回切。
