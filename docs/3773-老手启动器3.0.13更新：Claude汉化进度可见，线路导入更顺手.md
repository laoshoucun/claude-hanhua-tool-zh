# 老手启动器3.0.13更新：Claude汉化进度可见，线路导入更顺手

> 原文链接：[https://www.laoshoucun.com/jiaocheng/3773](https://www.laoshoucun.com/jiaocheng/3773)

点击「重启中文 Claude」以后，软件正在关闭旧窗口，还是正在加载语言包？如果一直没有进度，用户很难判断应该继续等，还是已经遇到问题。老手启动器这一轮更新，主要改善的就是这个过程。

除了让汉化进度可见，也处理了重启时反复出现的黑色命令窗口，并整理 Claude Desktop 的入口和线路导入方式。对于主要使用桌面版 Claude 的朋友，打开软件到找到线路这几步会更直观。

这一版更新了什么

体验修复：修复后台命令导致控制台黑窗反复出现的问题，并加强本次汉化辅助窗口的隐藏与退出清理。

启动优化：改进冷启动时的界面等待和开发者菜单识别，减少客户端尚未就绪导致的汉化失败。

进度优化：在 Claude 窗口显示汉化阶段和等待时间，按钮在处理期间保持忙碌状态，防止重复触发。

提示精简：保留实际失败原因，取消重复的进度弹窗和需要额外确认的成功提示。

入口调整：Claude Desktop 排在应用选择首位，新用户默认进入桌面版，已有用户保留上次选择。

导入优化：Claude 线路默认导入 Desktop，可自行勾选「同时导入 Claude Code」；分别反馈保存结果，并完善线路名称显示。

底部的「重启中文 Claude」：点下去以后按钮保持忙碌状态，Claude 窗口里显示当前汉化阶段

使用时可以留意什么

重启前先保存当前未完成的操作。处理过程中可以查看实际阶段；如果失败，按显示的原因排查，避免连续重复点击。
